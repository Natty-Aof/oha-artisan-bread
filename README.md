# OHA ARTISAN BREAD — ระบบบริหารร้าน

เว็บแอปบริหารร้าน: ลงเวลา (GPS + รูปยืนยัน), ลา/OT, สต็อกวัตถุดิบ, ผลิต & ขาย, ลูกค้าขายส่ง, สมาชิกสะสมแต้ม, ยอดขาย และแดชบอร์ด

- หน้าเว็บ: `index.html` (GitHub Pages)
- หลังบ้าน: `Code.gs` (Google Apps Script) เก็บข้อมูลใน Google Sheets และรูปเช็คอินใน Google Drive

## ติดตั้งหลังบ้าน (ครั้งเดียว)
1. สร้าง Google Sheet ใหม่ ชื่อ `OHA ARTISAN BREAD — Database`
2. เมนู **ส่วนขยาย → Apps Script** → ลบโค้ดเดิม วาง `Code.gs` ทั้งไฟล์ → บันทึก
3. เลือกฟังก์ชัน `setup` → **Run** → อนุญาตสิทธิ์
4. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone** → Deploy
5. คัดลอก URL ที่ลงท้าย `/exec` ไปใส่ใน `index.html` บรรทัด `const API_URL=''`

> แก้ `Code.gs` ภายหลัง: วางโค้ดใหม่ → บันทึก → รัน `setup` 1 ครั้ง → Deploy → **Manage deployments** → แก้ไข (ดินสอ) → Version: **New version** → Deploy (URL เดิม)

## ผู้ใช้และ PIN
- PIN เริ่มต้นแจ้งเจ้าของร้านแยกต่างหาก — ทุกคนเปลี่ยนได้เองที่ปุ่ม 🔑
- **อ๊อฟ (ADMIN_UID = u0)** เป็นคนเดียวที่ดู PIN ของทุกคน และตั้ง/รีเซ็ต PIN ให้คนอื่นได้ (เมนู พนักงาน & ตั้งค่า → 👁 แสดง)
- PIN เก็บ 2 แบบในชีต `pins`: แบบเข้ารหัส (ใช้ตรวจตอนเข้าระบบ) และตัวจริง (ให้อ๊อฟดูเผื่อมีคนลืม) — **ห้ามแชร์ Google Sheet นี้ให้คนอื่น**

## ความปลอดภัยที่มี
- ลงเวลาใช้ **เวลาของเซิร์ฟเวอร์** (แก้นาฬิกามือถือไม่ได้) และลงเวลาเข้าซ้ำในวันเดียวกันไม่ได้
- ตรวจพิกัด GPS เทียบหมุดร้าน + รูปยืนยัน (เก็บใน Drive ดูได้เฉพาะเจ้าของ/เจ้าตัว)
- พนักงานไม่เห็นยอดขาย และแก้ข้อมูลผู้ใช้/ยอดขาย/การตั้งค่าไม่ได้
- ใส่ PIN ผิด 6 ครั้ง ล็อก 10 นาที
